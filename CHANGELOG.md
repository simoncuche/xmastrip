# Versionshistorie

Die aktuelle Version steht immer zuoberst. `build.py` liest diese Datei und zeigt sie im Spiel
(Startbildschirm und Handy → Optionen). Format: `## x.y.z – TT.MM.JJJJ`, darunter Stichpunkte mit `- `.
